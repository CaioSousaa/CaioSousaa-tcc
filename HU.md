# Quadro – Histórias de Usuário (HU) do sistema Kanban proposto

| Código | História de Usuário |
| --- | --- |
| HU01 | Como visitante, eu quero me cadastrar e fazer login no sistema, para que eu acesse meus quadros de forma segura e persistente entre sessões. |
| HU02 | Como usuário autenticado, eu quero criar, listar, editar e excluir meus quadros, para que eu organize diferentes projetos separadamente. |
| HU03 | Como usuário de um quadro, eu quero criar, renomear, reordenar e excluir listas, para que eu estruture as etapas do meu fluxo de trabalho. |
| HU04 | Como usuário de um quadro, eu quero criar, editar, excluir e mover cards entre listas, para que eu acompanhe o progresso de cada tarefa. |
| HU05 | Como usuário de um quadro, eu quero excluir uma lista que contém cards, para que o sistema me informe claramente o que acontece com os cards associados. |
| HU06 | Como responsável por um card, eu quero adicionar checklists com itens marcáveis, para que eu visualize o progresso da tarefa diretamente no card. |
| HU07 | Como administrador de um quadro, eu quero convidar membros, definir seus papéis e atribuí-los a cards, para que eu controle quem pode editar o quê e quem é responsável por cada tarefa. |
| HU08 | Como usuário de um quadro, eu quero criar etiquetas coloridas e filtrar cards por elas, para que eu identifique rapidamente categorias ou prioridades entre várias tarefas. |
| HU09 | Como usuário de um quadro, eu quero comentar em um card, para que eu registre decisões e discussões relacionadas à tarefa e outros membros acompanhem o histórico. |
| HU10 | Como usuário de um quadro, eu quero definir prazos nos cards e visualizar quais estão atrasados, para que eu priorize o que precisa de atenção imediata. |
